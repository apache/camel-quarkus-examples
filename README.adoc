== AI integration

AI coding assistants can read the documentation as Markdown: https://camel.apache.org/llms.txt[llms.txt] indexes the Apache Camel documentation, and the https://camel.apache.org/camel-quarkus/latest/[Camel Quarkus documentation] covers the extensions. Pages on both are also available as Markdown by replacing `.html` with `.md` in the URL (for example, https://camel.apache.org/camel-quarkus/latest/reference/extensions/kafka.md).

The https://camel.apache.org/manual/camel-jbang-mcp.html[Camel MCP server] looks up components and their options and validates routes.

== Contributing

=== Branches

The `main` branch should always point at the latest https://repo1.maven.org/maven2/io/quarkus/platform/quarkus-bom[Quarkus Platform] release.
The `camel-quarkus-main` branch points at the Camel Quarkus snapshot version currently available in Camel Quarkus `main` branch.

=== Upgrading Camel Quarkus or Quarkus Platform BOM

See the dedicated section in https://camel.apache.org/camel-quarkus/latest/contributor-guide/release-guide.html#_upgrade_and_tag_examples[Camel Quarkus Release guide].
